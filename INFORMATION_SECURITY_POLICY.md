# Information Security Policy

**Version:** 1.0
**Effective Date:** October 2026
**Last Updated:** October 7, 2026
**Organization:** [Your Organization]

## 1. Purpose

This Information Security Policy establishes the framework for protecting [Organization]'s information assets in compliance with Kenya Data Protection Act (PDPA) and related regulations.

## 2. Scope

This policy applies to:
- All employees, contractors, and temporary staff
- All information systems and data
- All locations and remote access

## 3. Information Security Objectives

1. Protect confidentiality, integrity, and availability of data
2. Comply with Kenya DPA and regulatory requirements
3. Prevent unauthorized access and data breaches
4. Ensure business continuity
5. Maintain customer and stakeholder trust

## 4. Information Classification

### 4.1 Classification Levels

- **Public:** No restrictions on distribution
- **Internal:** Limited to [Organization] employees
- **Confidential:** Restricted to authorized personnel only
- **Restricted:** Highly sensitive; requires encryption and access controls

### 4.2 Classification Examples

- **Public:** Marketing materials, published reports
- **Internal:** General policies, non-sensitive procedures
- **Confidential:** Employee records, financial data, customer lists
- **Restricted:** Encryption keys, executive communications, system credentials

## 5. Access Control

### 5.1 Principle of Least Privilege

Users receive minimum access necessary to perform their duties.

### 5.2 Access Request Process

1. Manager approves access request
2. System administrator creates user account
3. Appropriate access permissions assigned
4. Access recorded in audit log

### 5.3 Access Removal

Access is removed immediately upon:
- Employee termination
- Role change
- Extended leave (>30 days)
- Quarterly access reviews

## 6. Password Management

### 6.1 Password Requirements

- Minimum 12 characters
- Mix of uppercase, lowercase, numbers, special characters
- Changed every 90 days
- No reuse of last 5 passwords
- Multi-factor authentication for sensitive systems

### 6.2 Password Practices

- Never share passwords
- Never store passwords in plain text
- Never use personal information in passwords
- Use password manager for complex passwords

## 7. Data Protection

### 7.1 Encryption

- Data in transit: TLS 1.2 or higher
- Data at rest: AES-256 for sensitive data
- Encryption keys: Secure storage with restricted access

### 7.2 Data Handling

- Minimize personal data collection (DPA compliance)
- Obtain explicit consent for data processing
- Maintain records of processing activities
- Implement data retention policies

### 7.3 Kenya DPA Compliance

- Establish lawful basis for data processing
- Maintain privacy notices
- Respond to data subject rights requests within 30 days
- Notify Kenya DPA of breaches within 72 hours

## 8. Incident Response

### 8.1 Incident Reporting

Employees must report incidents immediately:
- Security incidents: IT Security Team
- Data breaches: Data Protection Officer
- Policy violations: Compliance Team

### 8.2 Response Procedure

1. **Detection:** Identify and report incident
2. **Analysis:** Determine scope and impact
3. **Containment:** Stop ongoing attack or damage
4. **Eradication:** Remove cause of incident
5. **Recovery:** Restore normal operations
6. **Post-incident:** Conduct review and improve controls

### 8.3 Breach Notification (Kenya DPA)

- Kenya DPA: Notify within 72 hours if risk to individuals
- Data Subjects: Notify without undue delay if high risk
- Customers: Notify if business relationship affected
- Document: Maintain breach register with details

## 9. Security Awareness Training

### 9.1 Mandatory Training

- All employees: Annual security awareness training
- New hires: Training within first month
- Contractors: Training before system access
- Managers: Additional management-level training

### 9.2 Training Topics

- Phishing recognition and reporting
- Password security
- Data protection practices
- Incident reporting procedures
- Kenya DPA requirements
- Acceptable use of systems

## 10. Third-party Security

### 10.1 Vendor Assessment

All vendors processing data must:
- Demonstrate security controls
- Sign Data Processing Agreement (DPA requirement)
- Allow audit of security measures
- Maintain compliance with regulations

### 10.2 Vendor Management

- Annual security reviews
- Compliance audits
- Incident reporting requirements
- Service level agreements (SLAs)
- Breach notification agreements

## 11. Monitoring and Audit

### 11.1 System Monitoring

- Authentication logs reviewed daily
- System access logs reviewed weekly
- Network traffic analyzed for anomalies
- Database activity monitoring enabled

### 11.2 Security Audits

- Internal audits: Quarterly
- External audits: Annually
- Penetration testing: Annually
- Vulnerability scanning: Monthly

### 11.3 Audit Trail

All audit trails must:
- Be immutable (tamper-proof)
- Include user identification
- Record timestamp and action
- Be retained for minimum 12 months

## 12. Policy Exceptions

### 12.1 Exception Process

1. Document business justification
2. Identify risk mitigation measures
3. Get approval from Chief Information Security Officer
4. Document approval and compensating controls
5. Review exceptions quarterly

### 12.2 Exception Tracking

- Maintain register of all exceptions
- Track exception expiration dates
- Notify stakeholders of changes
- Remove expired exceptions

## 13. Compliance and Violations

### 13.1 Compliance Verification

- Compliance assessments: Quarterly
- Policy acknowledgments: Annually
- Training records: Maintained
- Audit reports: Published to leadership

### 13.2 Policy Violations

Violations may result in:
- First offense: Written warning and retraining
- Repeated violations: Suspension of system access
- Serious violations: Disciplinary action up to termination
- Criminal violations: Reported to authorities

## 14. Policy Review

This policy will be reviewed:
- Annually by Security Committee
- Following any security incident
- When regulations change
- When new threats emerge
