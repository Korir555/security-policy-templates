# Security Policy Templates

Kenya DPA-aligned security policy templates for enterprises, banks, and telcos.

## Included Policies

1. **Information Security Policy** - Overall security governance
2. **Access Control Policy** - User authentication and authorization
3. **Data Protection Policy** - Personal data handling (DPA compliance)
4. **Incident Response Policy** - Breach handling and notification
5. **Password Policy** - Password requirements and management
6. **Encryption Policy** - Data encryption standards
7. **Third-party Security Policy** - Vendor assessment and management
8. **Acceptable Use Policy** - Employee device and network use
9. **Bring Your Own Device (BYOD) Policy** - Personal device security
10. **Data Retention Policy** - How long to keep data
11. **Breach Notification Policy** - 72-hour DPA requirement
12. **Remote Work Security Policy** - VPN, device security for remote staff

## Kenya DPA Alignment

All policies reference and align with:
- Kenya Data Protection Act requirements
- Individual rights (access, correction, deletion)
- Lawful processing basis
- Purpose limitation
- Data minimization
- Consent requirements
- Breach notification (72-hour requirement)

## Customization

Templates are provided as Word documents (.docx) for easy customization:
- Replace [ORGANIZATION] with your company name
- Adjust thresholds and requirements as needed
- Add company-specific contact information
- Update approval authorities

## Usage

1. Select relevant policy template
2. Customize for your organization
3. Get approval from leadership
4. Distribute to employees
5. Train staff on new policies
6. Review annually or after incidents
